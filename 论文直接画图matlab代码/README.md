# 论文直接画图 MATLAB 代码

论文对比运行图一键绘制：**计划（基线）时刻表 + 求解结果时刻表**画在同一张图上，
基线为蓝色、求解结果为红色，自动输出 `.fig` 源文件与 `.png` 图片。

---

## 文件结构

```
论文直接画图matlab代码/
├── DrawFinalDataCompare.m            # 入口脚本（配置数据文件名、图名、输出路径）
├── DrawTrainDigramFunction_v3f_v5.m  # 核心函数库（v3→v3f 转换、背景、运行线、车次标注等）
├── README.md                         # 本说明
└── 最终数据/                          # 自备数据文件夹（本仓库不包含，需自行创建）
    ├── 基线.xlsx                     # 计划时刻表（基本图）
    ├── 有平行.xlsx                   # 有平行进路的求解结果时刻表
    └── 无平行.xlsx                   # 无平行进路的求解结果时刻表
```

两个 `.m` 文件必须放在同一目录（入口脚本会自动 `addpath` 定位函数库，
单独拷贝入口脚本到别处运行会报"找不到函数"）。

---

## 环境要求

- MATLAB R2022b 或更高版本（本项目用 R2022b 验证）
- Windows 环境（依赖 `xlsread` 读取 `.xlsx` 文件）

---

## 数据准备

1. 在本文件夹下新建 `最终数据` 子文件夹；
2. 放入三张 v3 格式时刻表，文件名固定为 `基线.xlsx`、`有平行.xlsx`、`无平行.xlsx`；
3. 数据格式（v3）：
   - 第 1 行为表头，第 1~3 列为 `NODE_ID | NODE_CODE | NODE_NAME`；
   - 此后每列车占 3 列：`车次_A`（到达）、`车次_D`（发车）、`车次_G`（股道）；
   - 到发时间为 Excel 时间格式（脚本读取后自动按时间先后生成停站顺序 SEQ）；
4. 数据要求：**求解时刻表的到发时间必须 ≥ 计划时刻表**（不得早于计划），
   否则图上会出现求解线早于计划线的现象；三张表应车站行数一致、按车次名列匹配。

## 运行方法

**方式一：命令行（推荐，无需打开界面）**

```bash
matlab -batch "run('E:\...\论文直接画图matlab代码\DrawFinalDataCompare.m')"
```

> 前提：MATLAB 已加入系统 PATH，否则把 `matlab` 换成完整路径，
> 如 `"C:\Program Files\MATLAB\R2022b\bin\matlab.exe"`

**方式二：MATLAB 界面**

直接打开 `DrawFinalDataCompare.m` 运行（F5）。图窗会前台显示，
可在图中缩放/编辑。

---

## 输出文件

脚本运行后在 `最终数据/` 文件夹生成 4 个文件：

| 文件 | 内容 |
|---|---|
| `对比运行图_基线_有平行.fig` / `.png` | 基线（蓝）+ 有平行求解结果（红） |
| `对比运行图_基线_无平行.fig` / `.png` | 基线（蓝）+ 无平行求解结果（红） |

`.fig` 为 MATLAB 图窗源文件，双击可重新打开继续编辑；
`.png` 为导出的论文用图（96 dpi，1800×1200 图窗）。

## 自定义修改

入口脚本 `DrawFinalDataCompare.m` 顶部的配置块：

```matlab
% 两组图配置：{计划文件, 求解文件, 图名, fig保存路径, png保存路径}
figs = {
    { fullfile(dataDir, '基线.xlsx'),   fullfile(dataDir, '有平行.xlsx'), ...
      '最终数据：基线(计划) vs 有平行', ...
      fullfile(dataDir, '对比运行图_基线_有平行.fig'), fullfile(dataDir, '对比运行图_基线_有平行.png') }; ...
    { fullfile(dataDir, '基线.xlsx'),   fullfile(dataDir, '无平行.xlsx'), ...
      '最终数据：基线(计划) vs 无平行', ...
      fullfile(dataDir, '对比运行图_基线_无平行.fig'), fullfile(dataDir, '对比运行图_基线_无平行.png') }; ...
    };
```

- 改数据文件名 / 图名 / 输出路径：直接改 `figs`；
- 增加对比组：按同样格式加一行 `{...}; ...`；
- 线路筛选：`LineID` 填 `1`（单线）、`'1,2'`（多线）、`''`（全线）；
- 颜色：计划线在 `DrawLineDigramColor` 第 7 参数（当前 `'b'`），求解线同理（当前 `'r'`）；
- 图窗尺寸：`set(gcf, 'Position', [100, 100, 1800, 1200]);`
- 图例文字：`legend({'计划(基线)', '求解结果'}, 'Location', 'northeast');`

## 绘图逻辑说明

1. 读取两张表 → `ConvertV3toV3f` 转 v3f 格式（自动生成 SEQ 停站顺序）；
2. 时间轴取两表并集（最早起点 ~ 最晚终点）；
3. 背景以计划表为基准：Y 轴车站间距 = 区间最小运行时间（等价于站距），
   X 轴为时间，绿色网格为整小时/10 分钟线；
4. 先画计划（蓝线），再叠画求解结果（红线）；
5. 车次号按计划表标注（黑色），位置为该车最早到达站上方；
6. 图例区分"计划(基线)"与"求解结果"。
