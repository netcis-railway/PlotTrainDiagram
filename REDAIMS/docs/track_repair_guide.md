# 股道信息修复

更新：2026-10-26。基本图与普通 run 使用同一分配规则；主界面和独立时刻表编辑页均提供入口。

## 导入时修复

1. 上传 Excel，执行四表预检（普通 run 只导入 TTT，股道资源取当前回溯有效基本图）。列车必须有 `车次_A、车次_D、车次_G、车次_SEQ`，缺少 `_G` 时按车次给出阻断错误及拟插入位置。缺列不等于现有 `_G` 单元格为空，不会将 `_SEQ` 识别成股道。
2. 在预检结果点击“修复股道信息”。不必先通过预检或导入；也可恢复未提交的预检后修复。
3. 窗口列出全部列车；每条线路占一列，列内有线路、UB、DB三个复选框，可横向滚动。默认选中缺列或存在空股道的列车，按途经车站在 NODE_INFO 的所属线路勾选全部相关线路。用户可以增减线路、修改方向，两个方向可以同时勾选。
4. 默认方向从 `_A` 前车次提取；有 `/` 时只看第一个车次，以其末尾数字奇数选下行 DB、偶数选上行 UB，例如 G109→DB、G108→UB、G1914/G1911→UB。不能识别数字时不猜测，请手动选方向。
5. 点击“确认”，为所选列车的全部有效访问重新分配股道，补入其缺失 `_G` 列，自动重新发起预检。未选列车缺列仍报错，其他错误仍需处理。确认日期、警告及所属类别后，再正式导入。

修复只生成内存中的文件副本供重新预检，原 Excel 与原预检暂存不改写；正式导入采用修复后文件作为受管来源。可通过已有 Excel 导出功能保存修复结果。其他表头、SEQ、到发时刻、车站基础资料存在阻断错误时，先修正这些错误再分配；不会跳过错误访问而宣告修复成功。

## 已导入时修复

在基本图或 run 编辑器点击“修复股道信息”，选择列车、线路和方向后确认。当前已输入的到发、日期和股道草稿参与计算；生成的股道写入当前草稿，并自动显示股道列。不会立即提交到库，仍按“校验 → 处理问题 → 保存”的流程操作；放弃修改可恢复原值。导出会生成完整 A/D/G/SEQ 列组。

修复窗口显示所有列车，不受编辑网格的线路、车站和列车显示筛选限制。未选列车股道保持固定，参与避让；未选列车股道缺失或无效时明确提示其占用无法检查，建议一并选择修复。

## 分配规则与失败处理

- 候选股道只来自本站、用户勾选线路及方向的 NODE_INFO 配置；合并去重到发线和非空正线，保持真实正整数编号。多个所选线路和方向取 OR，不跨车站借用编号。未知方向不猜测，已知的其他选中方向有资源时仍可使用。
- A=D的通过访问优先正线，其次到发线；其余访问优先到发线，其次正线。正线兼作到发线仅占用一个编号；没有正线合法。相同角色按股道数字升序优先。
- 冲突以同一对象中的物理“车站身份＋股道号”为键，跨线路同号不能重复占用；不把基本图与 run 当作同时运行的两个方案。占用按累计秒（含跨日偏移）的半开区间 `[A,D)` 比较，相接的结束/开始时刻可复用。A=D或仅有一个到发时刻时，按现有秒精度保留 `[t,t+1秒)`；两者均缺失、D早于A则拒绝分配。
- 先固定未选列车的既有占用，再对各站所选列车求解，优先安排候选最少的访问，必要时回溯，避免简单贪心造成可解数据误判。分配结果避免与所有已知固定占用和其他生成占用重叠；未选列车的未知占用不能视为已校验。
- 容量不足、没有匹配资源、未选列车已占股道但缺少有效时间，均显示车次、站名和原因；整次操作不应用任何修改，不通过改时刻或抢占未选股道“消除”错误。每站最多500条待分配访问，最多20000次搜索；达到上限提示缩小选择范围，不声称数据必然无解。
- 修复上下文绑定源文件、对象修订、草稿和实际基本图。数据变化后旧窗口确认返回409，请重新打开。算法不修改原始到发、SEQ、车站、线路、基准日期或类别。

本功能为明确触发的股道生成及相关占用避让；全库冲突分析、进路/道岔冲突和车站间隔等仍属于后续独立功能。


## 2026-10-26：SEQ缺列修复与整车平移

同一列车同时缺少_G与_SEQ时，先通过“修复SEQ信息”补SEQ，再执行股道修复。股道窗口直接提示先修复SEQ；不能跳过缺SEQ访问后宣告股道分配完成。 详见[SEQ修复](sequence_repair_guide.md)与[整车平移](time_shift_guide.md)。


## 线路表头整列选择（2026-10-26）

每个“线路x”表头均有复选框。取消勾选时，清除该线路下所有列车行的“线路、UB、DB”，包括搜索隐藏的行与未勾选修复的列车；不影响其他线路或左侧列车选择。整列没有任何子项勾选时表头不选中，部分选择时显示中间状态。

重新勾选表头时，为全部列车启用该线路并恢复各车默认方向：奇数下行DB、偶数上行UB；无法识别车次数字的方向仍留给用户手动选择。无需同时勾选UB和DB，用户仍可逐行修改。初始状态只在各车相关线路勾选线路和默认方向，无关线路保持全部不选。

取消线路后，如果某个已选列车没有任何可用线路/方向，确认按钮不可用；请补选其它线路/方向，或取消该列车的修复选择。提交时不包含已取消的线路。
