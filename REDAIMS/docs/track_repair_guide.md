# 股道信息修复

更新：2026-10-27。基本图与普通run共用以下规则，主界面和独立时刻表编辑页均可操作。

## 保存与取消

- “保存”：生成并应用当前选择下可修复的股道。编辑器中写入当前草稿，仍需在主编辑器校验、保存；导入窗口中生成Excel副本并自动重新预检，仍需确认导入。
- “取消”：关闭当前修复窗口，不应用修复结果，不改当前编辑草稿、源Excel或数据库。保存请求尚在处理时也可取消；请求会中止，延迟返回的结果不会应用。
- Esc与“取消”一致。保存只在修复上下文加载成功、选中列车且各所选线路有唯一方向时可用。

## 默认：只补缺失股道

默认选中缺_G列或存在空股道的列车。空值、空字符串视为缺失；即使整车被勾选，已有非空股道也保持原值。非空但无效的编号给出告警，不作为空值自动覆盖。

候选取本站、所选线路和方向的真实股道。停站优先到发线，通过优先正线；不改变到发时刻、SEQ、日期或车站/线路。所有已有有效股道占用先保留，包括未选列车以及窗口中后出现的列车，避免新分配抢占已有占用。

缺失访问分站增量分配，已生成的缺失股道允许在其候选范围内回溯调整，以免简单贪心造成可解数据误判。容量不足、资料未知或没有可用资源时，对该访问告警并保留原值，其余成功结果仍可保存。每站最多安排500条缺失访问，最多20000次搜索；达到限额告警并保留其余访问，不声称数据必然无解。

## 既有冲突检查与可选修复

窗口打开时就检查已有有效股道占用，显示车次、车站、股道及冲突列车。默认只报告告警，不改变已有分配。

勾选“修复有冲突的股道分配”后，自动选中涉及既有冲突的列车，用户可再手动调整选择。顺序按本窗口列车从上到下确定，同车访问按SEQ顺序检查：

1. 保留先出现列车的既有股道。
2. 后续已有访问仍与前面保留的占用冲突时，只对已选列车尝试改分配。
3. 避让其他全部已有占用，包括未选列车、后出现但已有分配的访问，以及已修复的占用。
4. 每次成功后立即更新占用，再处理后续访问。前一个冲突被修复后，已不冲突的后续访问保持原值。
5. 无资源或容量不足时保留该访问原股道，报告未解决冲突，继续其他可修复项目。

取消勾选此选项后，已有股道恢复为只检查、不自动改分配的规则。冲突修复处理完成后，再分配缺失股道。所有告警都需人工核对，修复成功不等于全局运行方案已经无冲突。

## 线路与方向选择

每车每线路的UB/DB为二选一，选中一个自动取消另一个；可以选择多条线路。默认方向取第一个“/”前车次末尾数字，奇数DB、偶数UB；无法识别时手动选择。

线路名下新增UB/DB互斥选项。选中表头UB或DB后，为该线路全部途经列车启用线路并统一方向，包括搜索隐藏行和当前未选修复的列车；列车本身是否参与修复的勾选保持不变，同车本线路所有车站均使用此方向。各行方向一致时表头显示该方向；个别行改为另一方向后，表头不显示统一选择。

未经过某线路的列车，其线路选择及UB/DB灰显并禁用，批量操作也不会启用这些单元格，提交时排除这些线路。是否途经使用修复上下文的related_lines。线路下没有途经列车时，表头线路复选框及UB/DB也禁用。

线路表头取消时清空该线路下全部行的线路、UB、DB（包括隐藏行和未选列车）；恢复时仅为途经列车启用该线路，并按各车默认方向选择。没有方向或没有线路的已选列车不能保存。

## 时间、未知资料与校验边界

- 按同一对象中的物理“车站＋股道号”检查占用，跨线路同号仍视为同一资源；不把基本图与run视为同时运行的两个方案。
- 时间用累计秒的半开区间[A,D)。相接的占用不冲突；到发相同或仅有一个时刻时占用1秒。
- 未知线路/方向资料告警；有其他已知所选线路候选时可使用，没有候选时保留原值，不自动套用未选方向。
- 已有股道或时刻无效时告警，明确其占用无法核查。缺失股道访问存在时刻倒置/完全无时刻，以及表头、SEQ等结构问题，仍须先按原校验规则修正，不能伪造时刻完成修复。
- 上下文绑定源文件、对象修订、草稿和实际基本图；源数据变化后旧请求返回409，请重新打开窗口。

## 导入与已保存数据

导入的列车仍需A/D/G/SEQ四列组。已选列车缺_G列会补入，未修复的单元格保留原值；未选列车缺列继续由预检提示。原Excel与原预检暂存均不改写，可通过导出保存修复结果。

在已导入基本图/run上，修复结果仅进入当前草稿；窗口取消不撤销打开窗口前已经存在的草稿，也不产生新的修改。后续按主编辑器“校验→处理告警→保存”提交。

同车同时缺_G和_SEQ时，先[修复SEQ](sequence_repair_guide.md)，再补股道。整车时刻平移规则见[整车平移](time_shift_guide.md)。本功能不替代后续的全库冲突、进路/道岔冲突及车站间隔分析。
