# 基本图四表查看、编辑与导出

选中基本图，在“查看编辑”或“基本图”页面点击“**四表原始数据**”。原有“时刻表编辑”继续保留；切换方式前先保存或放弃当前修改。

工作表下拉框列出时刻表TTT及LINE_INFO、NODE_INFO、MINIMUM_RUN_TIME。表格保留Excel表头、列字母、原行号和原行列顺序。默认每页25行、每组40列；使用“前一组列”“后一组列”查看宽表其余列，使用“上一页”“下一页”查看其余行。切换行页保留当前列组，切换工作表从第一组列开始；点击校验问题会定位到对应行页与列组。可编辑已有数据单元格，表头和合并区域的非首格不允许直接修改。本版不提供新增/删除行列。

四表共享一份草稿，切换工作表、行页和列组不丢失修改。草稿暂存于当前浏览器会话；重新打开同一基本图时恢复。基本图已被其他窗口修改时保留旧稿并阻止直接保存，需要核对并放弃旧稿后重新载入。预览先取得数据库一致快照，随后释放数据库锁再解析Excel，避免预览期间阻塞运行图、实验等其他查询。

到发时刻按当前运行基准日显示完整日期。可输入`YYYY/MM/DD hh:mm:ss`或累计`HH:mm:ss`（允许超过24小时）。空内容清空单元格。已有数字、日期和布尔值保持对应类型；布尔值填写TRUE/FALSE。

点击“**校验四表**”会执行完整四表解析，以及节点身份、线路映射、股道、SEQ、时间和跨对象约束校验。问题列出工作表和单元格，点击问题切换至相应页。跨表关联字段需保持一致；不会自动改写其它表来绕过校验。点击“**保存**”也会先校验；阻断错误不能提交，警告和列车基准日变化需核对确认。

保存更新基本图数据库工作数据及受管Excel工作副本，增加内容修订，保持基本图身份和存储位置；未改变的列车及访问保留ID。受管副本采用新文件写入成功后再提交数据库引用的方式，写入失败或事务失败保留旧工作状态。普通时刻表编辑的基本图保存也会同步工作副本。

最初导入的受管来源文件保留用于追溯，与可更新的工作副本分开。用户上传前的外部Excel不会被自动改写。工作副本保留原工作表布局、表头、常规样式和额外工作表；完整日期随当前数据库同步，不再显示导入时的1900年占位日期。

点击“**导出基本图和线路数据**”先将当前数据库四表更新到受管Excel工作副本，写入成功并校验摘要后，读取该副本的实际文件字节导出。时刻表以外的其他线路数据表、公式、图片等包内容继续保留，导出不受当前所选工作表或分页限制。存在草稿时先保存或放弃。支持文件保存选择器的浏览器可选择文件名和位置；Firefox等浏览器下载Excel，位置由浏览器设置或保存对话框决定。Linux部署时文件保存到用户浏览器所在电脑，不要求浏览器访问服务器磁盘路径。

导出Excel中的列车_A、_D列统一使用`hh:mm:ss`单元格显示格式，不在单元格中显示年月日。实际值仍为完整日期时间，保留运行基准日与跨日偏移，可在Excel编辑栏或调整单元格格式后查看日期。此规则适用于基本图、run、另存和外部同名表替换；网页四表编辑仍显示完整日期以便核对。

“时刻表编辑”中的导出窗口也使用这一流程。勾选项表示从数据库更新哪些表单，默认勾选四表；未勾选的表单保留副本中的原内容，其他附加表不会被删除。run的三张基础表取当前有效基本图，缺少基本图时只更新TTT；run原文件缺少基础表时会补入所选基础表。更新副本不修改时刻表业务数据或内容修订。

默认“另存新文件”返回完整受管副本。保留原“选择源文件并替换同名表单”功能：先同步受管副本，再将所选表单更新到用户重新选择的目标工作簿，保留该目标的其余内容；目标缺少所选同名表时仍拒绝替换。原始导入来源文件继续保留。
