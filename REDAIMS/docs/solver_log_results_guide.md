# 求解日志结果属性

导入日志时同时识别目标函数最优值和求解时间，显示在“求解结果”中；也可在日志查看页选中文件后编辑。两个字段各有独立来源：自动获取为“求解日志”，人工保存修改后为“人工填写”；未获取时显示提示，便于补填。

## 获取口径

当前支持Gurobi的Best objective最终摘要和Explored…in…seconds总时间，以及明确标注Objective/Objective value/Final objective、目标函数最优值/目标值、Solve/Solving/Solution/Optimization time、求解时间/求解耗时等结果行。识别科学计数法、千位分隔符、正负目标值及零值；毫秒、分钟和小时转换为秒。使用导入识别到的UTF-8或GB18030编码。

目标值取最终解的目标值；未证明最优时是日志报告的最好可行解目标值。不会把最优界、根松弛目标、进度表数字或时间限制当成最终结果。无法识别或值非有限时保留为空；后续明确缺值或新的Gurobi模型段会清除之前段落的结果。缺值不阻止导入，原文件仍可查看、下载。

## 编辑与来源

结果属性属于日志附件，同一日志在不同保存展示中使用相同的值和来源。

- 目标函数最优值允许负数、零和科学计数法；求解时间以秒输入，须为非负有限数值。
- 点击“保存求解结果”仅提交有实际变化的字段，对应来源改为“人工填写”；未改字段保留原来源。
- 可明确清空字段，来源仍为“人工填写”，界面提示尚未填写。保存失败保留输入。
- 修改结果不改写日志正文、摘要指纹、求解器识别或小节备注。已保存分析仍引用原日志附件。
- 重复导入同名同内容文件复用原附件，不覆盖人工值。旧附件缺少识别记录时，可重新导入相同文件补充识别，仍保留人工字段；旧附件的读取不会自动扫描全文。

服务器启动时为旧日志表自动补充字段。识别代码位于backend/app/solver_visualizers/results.py；原plot_gurobi_progress.py文件名、作图接口和求解器关键词JSON配置保留。
