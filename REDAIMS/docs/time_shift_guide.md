# 所选列车整条运行线时间平移

更新：2026-10-26。此功能已在基本图与普通 run 共用编辑器实现，主界面和独立标签页均可用。

1. 打开时刻表，点击“整车时间平移”。
2. 选择一个或多个列车。窗口默认采用“列车选择”中的初选范围，也可以搜索、全选或手动调整；清空与搜索只改变选择，不删除数据。
3. 输入非零整数平移量，单位选择分钟或秒。正数表示推迟，负数表示提前。例如5分钟为推迟300秒，-120秒为提前2分钟。
4. 点击“生成平移草稿”。在现有草稿上对所选列车全部访问的非空A/D加上相同偏移，包含当前线路、车站筛选隐藏的访问；不能只修改网格当前可见部分。到发空值、股道、SEQ、节点和来源均保留；未选列车不改。
5. 核对生成结果，点击“校验”，处理提示后“保存”。跨午夜继续保留累计秒/日偏移，正常校验显示列车实例基准日变化并要求确认。生成草稿本身不提交业务数据，源 Excel 不变；可通过现有“放弃本次修改”放弃草稿，再通过已有 Excel 导出功能导出已保存数据。

平移结果早于运行基准日时拒绝，不自动绕到次日。需要提前到前一天时，先正确调整基准日期再平移。日期越界、旧修订、外国列车ID、重复选择、零偏移、无可平移时刻、无效输入均拒绝；存在原草稿阻断错误时先修复。每次按最终整体状态检查，不应用部分结果；保留原草稿供修改后重试。

平移只检查格式、引用、日期和既有保存完整性，不做运行可行性、股道冲突或自动调度，也不改其他列车以消除冲突。基本图平移只更新基本图，run平移只更新该run；run仍使用实际回溯基本图作为基础资源。没有新增归档、历史撤销或图形拖动平移机制。
