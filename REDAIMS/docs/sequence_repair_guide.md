# 缺失 SEQ 列的检查与修复

更新：2026-10-26。

基本图与普通 run 的导入预检，均逐车检查 A、D、G、SEQ 四列组。缺少 `_SEQ` 时显示表单、拟插入位置和具体车次；不会把后面列车的列错认为当前列车的数据。允许定位仅缺 G、仅缺 SEQ、同时缺 G/SEQ 的情况；缺 A/D、错序、重复组仍须修正原表。

## 操作流程

1. 上传并预检，或恢复尚未提交的预检任务。
2. 点击“修复SEQ信息”，窗口列出全部列车及表单、有时刻的访问数、源起止行。默认勾选缺少 SEQ 且有到发时刻的列车；已有 SEQ 的列车不能勾选重编号。
3. 确认修复后，生成文件副本并自动重新预检。源 Excel、原任务暂存及已导入对象保持不变；后续正式导入使用修复后的文件副本。
4. 若同时缺少 G 和 SEQ，先修复 SEQ，重新预检后再点击“修复股道信息”。未选列车缺列、其他格式和跨对象一致性问题仍需处理。
5. 重新核对日期、列车基准日、存储类别及预检警告，正常确认导入。

## 生成规则

每个所选列车的新 SEQ 列按当前源表行号升序生成：该行 A 或 D 至少一项非空，则依次填 1、2、3…；两项均为空则不生成编号。行号可跳过，编号不跳过。例如第2、5、9行有时刻，生成SEQ=1、2、3，而不是1、4、8。只看原表行序，不按到发时刻、NODE_IND或NODE_SEQ_OF_LINE重新排序。不会改写 A/D/G、其它列车、车站及基础表。

没有任何到发时刻的列车不能生成 SEQ。仅有孤立 G 值且没有 A/D/SEQ 的行不获得 SEQ，预检给出“不作为列车访问”的警告，原G值保留在源文件副本和预览中；显式已有SEQ的访问即使缺时刻仍保留。其余不完整数据由重新预检继续定位。时间值是否有效仍按原时间解析规则检查，补号不会把无效时间自动变为合法时间。

此规则只用于用户明确选择的新补列。已有 SEQ 仍允许任意正整数起号、任意表格行序，但同车唯一且连续；已有列的空值、重复、断号不通过此按钮偷偷重编号。全局同实例 SEQ 一致性约束不绕过：自动从1生成后若与现有基本图/同路网对象不一致，重新预检会继续报冲突，应核对源表或实例日期。

同车多表仍不自动合并：修复以每个表单列组独立补列，后续预检按既有规则要求确认片段/实例整理。多文件导入继续后置。
