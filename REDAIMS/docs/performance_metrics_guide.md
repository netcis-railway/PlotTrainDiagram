# 单run指标分析

在“运行图分析工作区”的顶部按钮行，或“3. 延误预览”小节中，点击“指标分析”。两个入口打开同一指标页。点击“返回运行图分析工作区”回到原分析页，保留运行图、日志、延误小节的已读取状态、筛选、展开及工作区滚动位置。指标页本身的配置也保留。指标配置侧栏打开时Esc先关闭侧栏；否则Esc返回工作区，再按Esc才关闭分析窗口。

实验窗口也提供这两个入口，使用“3. 延误预览”当前选择的成员run。指标页明确显示成员名称，只计算单个run；返回后可以切换成员再打开，每个访问过的成员保留独立配置。实验窗口沿用原来的保存边界，不把结果保存到某个成员run。

## 指标与范围

首版采用“总览与指标侧栏”。默认四项为累计、平均、最大晚点和晚点率。预设还包括“终到评价”“晚点分布”；配置侧栏可以从十项中选择2至6项，取消不会应用草稿。

| 指标 | 口径 |
| --- | --- |
| 累计晚点 | 所选事件的正晚点求和；提前不抵消晚点 |
| 平均晚点 | 默认累计晚点除以全部有效事件数；到达、出发均值均可取消“包含零晚点事件”，改为仅对相应偏差>0的事件取平均 |
| 最大晚点 | 全部有效事件的非负晚点最大值 |
| P95晚点 | 非负晚点含零值升序，取第ceil(0.95×N)个 |
| 晚点率 | 偏差严格大于阈值的事件数除以有效事件数 |
| 沿途受影响列车数 | 范围内存在超阈值事件的列车，每车计一次 |
| 终到累计晚点 | 有效终到到达正晚点累计，每车一次 |
| 终到平均晚点 | 终到累计晚点除以有效终到列车数 |
| 终到晚点列车率 | 终到到达偏差严格大于阈值的列车数除以有效终到列车数 |
| 受影响列车数（终到） | 终到到达偏差严格大于阈值的列车数，每车计一次 |

各指标解释及配置侧栏提供可排版的数学公式。a、d分别为run到达、出发时刻，上标0为图定时刻。终到累计晚点为：

$$
\sum_{k\in\mathcal K_D}\max(0,a_{D_k,k}-a^0_{D_k,k})
$$

D_k为列车k在基本图完整路径的终到站，集合K_D只包含当前范围内可计算终到到达偏差的列车。终到指标使用到达符号a，提前不抵消晚点。百分比指标同时展示有效样本分母；无有效样本仍显示“—”。

平均到达晚点和平均出发晚点卡片标题旁均提供“包含零晚点事件”，默认勾选，保持原统计口径。取消后，分母仅为相应到达或出发偏差严格大于0的事件数，正点、提前和缺失均不进入分母；不受晚点阈值影响，也不改变其他指标。卡片显示平均值实际样本数，公式和说明同步切换；没有正晚点事件时显示“—”。到达和出发开关独立记录，切换观测事件后保留各自选择，随分析快照保存；旧快照缺少出发开关时默认勾选。

最大晚点卡片同时显示对应车次及车站；并列最大值保留全部列车和访问位置，重复经停以访问序号区分。卡片显示简要名单，悬停标题或点击后在解释区查看完整名单。全部有效事件均未晚点时显示“无晚点列车”，不指定任意一趟列车。

“终到评价”预设中的受影响列车数专指终到超阈值列车，与沿途受影响列车数分别保存。点击其“查看终到晚点列车”下拉菜单，按终到到达晚点降序列出车次、列车基准日、终到站、晚点时长；相同时长按车次、日期及稳定ID排序。名单每页最多20项，翻页不改变统计结果。点击车次联动曲线，不修改统计筛选。恰好等于阈值、提前、无时刻或未匹配完整终到的列车不进入名单。

旧版“终到评价”的四项组合在打开时将原通用受影响指标转为终到专用指标，原快照数据不改写；其他自定义组合继续保持原沿途口径。

沿途指标可切换到达/出发；终到指标始终使用到达事件。阈值默认0秒，允许0至86400秒，内部以秒保存。切换显示秒/分钟不改变阈值含义。零有效样本显示“—”，不把缺失补零。

统计范围默认整个run，也可明确选择列车和车站。通过访问按所选到达/出发事件参与；重复经停分别统计，不将到达和出发相加。筛选选择可搜索，长列表一次显示前80项；全选/清空作用于全部候选项。空选择保持为空。有效及无可计算事件数明确显示，后者包含始发无到达、终到无出发等不适用事件，不将缺失推断为取消列车，也不虚构未匹配事件。

终到访问由后端对run和基本图完整访问顺序核对，始发/终到须分别对应基本图的首/末访问。重复SEQ、无法匹配、终到时刻缺失、run只到基本图中间站时不计算终到指标；不会改用当前筛选中最后一个站或最后一个非空时刻。车站筛选未包含真正终到时，也排除该列车的终到样本。这里的路径边界以基本图所含数据为准。

## 图形与性能

结果区按三行排列，每项独占整行宽度：第一行“到发偏差曲线”，第二行“到达/出发偏差热力表”，第三行“到发晚点时空热力图”。热力表标题随观测事件和显示单位切换。

热力表显示有符号偏差：负值提前、正值晚点、0与图定一致；无可计算时刻显示“—”及原因。每页最多25个访问行、20列车，即500个数据单元格。翻页、选中单元格或高亮列车不改变统计范围，指标始终统计所选范围的全部事件。

新增“到发晚点时空热力图”，与原表格同时保留。横轴为事件实际发生的日历时间，可选1分钟、10分钟或1小时；纵轴按车站排列，每站固定32像素，不按物理距离拉伸。同一车站的重复经停合并统计。时间范围从首个有效事件所在日的00:00开始，到最后一个有效事件次日00:00结束；跨午夜不折回同一天，整点事件进入右侧新时间格。

设时间格为半开区间I_b=[t_b,t_b+Δt)，选择事件类型集合F为到达、出发或两者。车站i、时间格b的颜色值为：

$$
H_{i,b}=\sum_{k}\sum_{v\in\mathcal V_{i,k}}\sum_{e\in F}\mathbf{1}\{t^e_{i,k,v}\in I_b\}\max(0,t^e_{i,k,v}-t^{e,0}_{i,k,v})
$$

其中V_{i,k}为列车k对车站i的访问集合，v区分重复经停；t为实际时刻，上标0为图定时刻。仅计入具有实际时刻及有效图定比较值的事件。提前不抵消正晚点，零晚点仍计入有效事件数；到达与出发同时勾选时分别累计。同车重复访问分别计入对应时空格。图中数值随页面秒/分钟单位切换，分格宽度始终由时间分辨率决定，不受晚点阈值和均值卡片的零晚点开关影响。统计列车和车站筛选沿用页面设置，绘图曲线的多选不改变热力图范围。

颜色从深蓝紫到青绿、黄色，当前范围最大累计值对应最亮颜色；色标注明每格累计值，颜色表示晚点值之和，不单独表示列车数量。指向或点击时空格可查看完整车站名、起止日期时间、累计晚点、有效到达/出发事件数及晚点事件数，空格显示0和0个事件。细分时间后可横向滚动，车站较多时纵向滚动，车站名和时间刻度保持可见；聚焦画布可用方向键逐格查看，Home/End到首/末时间格。稀疏聚合与可见区域绘制避免生成全量网格DOM或超大画布。

旧快照缺少实际时刻时明确提示重新计算，不从晚点差值猜测发生时刻、不静默读取当前数据库；原指标、表格及到发偏差曲线仍可查看。时间分辨率和事件开关随指标快照保存，包括明确取消全部事件的状态。

“到发偏差曲线”的列车下拉菜单支持复选。候选列车按完整路径中正到达偏差事件的平均晚点从大到小排列；与统计车站筛选、晚点阈值及均值卡片的零晚点开关无关。选项显示“G345  2025/04/08 (平均到达延误 xx分钟)”，固定使用分钟；无正晚点或无有效到达事件时分别提示。搜索支持车次及日期，每页最多80项；搜索、翻页保留选择，“全选搜索结果”作用于全部匹配项。

列车菜单旁提供“绘图车站”多选下拉菜单，默认选择全部车站。可按中文名称或站名搜索，每页最多80项，支持翻页、全选车站及清空车站；搜索与翻页保留已选项。选择同一车站时保留各次经停。绘图车站独立于统计车站范围，同时作用于二维曲线与三维图；清空后显示选择提示。曲线列车的均值排序继续使用完整路径，不随绘图车站改变。

“2D延误演变曲线”“3D延误演变曲线”为左对齐的二选一单选项，默认2D，单选或多选列车都可明确切换。2D将所选列车叠加到同一图中，横轴为所选车站、纵轴为有符号偏差；单车保持SEQ顺序，多车使用共同车站访问行及统一延误刻度。同一列车的到发曲线使用相同颜色，实线为到达、虚线为出发；颜色图例显示车次与日期，并与3D模式对应，点击图例可强调该车。较长图例每页最多80项；所有有效事件参与路径，辅助点标记限制总量以控制渲染开销。

3D显示可旋转的瀑布带，每趟列车占一个独立位置，X轴为所选车站、Y轴为车次号、Z轴为偏差。车站使用共同访问行，重复经停分别定位；不同列车之间不连线或填充曲面。两种模式共享独立的“到达延误”“出发延误”开关，负值保留为提前，缺失时刻断开；隐藏的有效经停跳过，但隐藏位置的缺失时刻仍使曲线断开。统计列车范围决定可选列车池，模式、绘图选择和到发开关不改变指标口径。清空绘图列车、绘图车站或取消全部事件时显示选择提示。

三维图支持鼠标/触摸拖动旋转、滚轮缩放、角度和缩放滑块、重置按钮；聚焦画布后可用方向键旋转、加减键缩放、Home重置，双击也可重置。指向数据点查看车次、日期、车站及偏差，点击联动热力表明细。热力表或终到名单点击车次时，原来仅选一趟时切换到该车，多选时保留原选车并加入该车。三维高密度数据自动采用线框，仍绘制全部选中列车。图形随容器宽度调整。

当前实现总览、配置侧栏、热力表、时空晚点热力图及二维/三维到发偏差曲线；研究工作台、排序/分布专用图和报告/雷达模板作为后续扩展。

## 保存、快照与数据

分析仅使用已保存的run和有效基本图，不提交时刻表草稿。已有延误数据时可直接使用已读取快照；“重新计算当前已保存数据”显式读取新数据，并保留当前指标和有效筛选项。

“保存指标分析”创建run下独立的“指标分析”子节点（metrics类型），默认名称为“指标分析 · 时间”，保存浮窗中的类型固定为指标分析，可输入名称和备注，无需滚回页首。打开保存节点后，在顶部修改名称、备注并点击“保存名称和备注”，只更新原节点属性；快照和配置保持不变。保存整个已读取工作区，同时记录指标配置、观测事件、均值零晚点开关、阈值、单位、统计筛选、曲线多选列车、绘图车站、2D/3D显示方式、到发开关、三维视角、热力表分页及完整输入快照。分类树用矩形框内的加粗大写P图标区分，回看直接进入指标页；点击返回即可查看同一节点保存的工作区。旧版delay类型的指标快照仍保留并可打开，重新点击“保存指标分析”会另存为metrics类型。缺少显示方式时默认2D，缺少多选设置时按旧高亮列车恢复单车曲线，绘图车站默认全选，到发均显示，零晚点默认包含；明确保存的空选择保持为空。旧快照没有路径端点时，沿途指标可计算，终到指标显示“—”，只有明确重新计算才读取当前数据。

数据快照冻结，不随后续时刻表修改变化；不承诺从旧输入文件重新求解或重建历史数据库。沿用32MB节点大小限制，保存失败不会部分写入。指标分析与延误预览使用独立节点类型及同一分析节点存储表；名称按run与类型分别去重。后端启动自动为新旧分析节点及旧视图补充notes字段，旧备注默认为空，不改写原有快照。

指标页顶部的已保存项目属性将子节点类型、名称上下排列，仍可编辑名称和总备注；返回工作区后可为运行图、求解日志、延误预览分别保存小节备注，子节点可继承所属run或使用自己的覆盖。详见[run分析工作区指南](run_analysis_guide.md)。
