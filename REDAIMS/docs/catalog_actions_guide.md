# 项目分类树快捷操作

右键分类树条目时，会先选中该条目，再显示快捷菜单。左键选中条目后，“查看编辑”中的“操作”栏提供相同操作和可用状态。

| 选中条目 | 操作 |
| --- | --- |
| 研究员、路网、场景、案例、算法 | 导入基本图；查看基本图(运行图) |
| 批次 | 导入基本图；导入时刻表 |
| 基本图 | 编辑基本图(时刻表)；查看基本图(运行图)；删除基本图 |
| run | 编辑时刻表；查看运行图；导入求解日志 |
| 视图（run子节点） | 查看保存视图 |

- 导入基本图自动带入当前类别；批次导入时刻表自动带入当前批次，沿用现有 Excel 预检和正式提交流程。
- 普通类别查看当前有效基本图，包含继承的上级基本图。读取中或无可用基本图时，该操作暂不可用。
- 编辑操作定位到当前对象的时刻表；运行图沿用该时刻表的草稿和基准日，待数据加载完成后打开。
- 删除基本图先展开删除影响预览，再按原有依赖检查和确认流程删除。
- 基本图条目在“查看编辑”中展示详情与时刻表，和其物理所属类别分别保持选中状态。

菜单支持鼠标操作，以及 Shift+F10 或菜单键打开、上下方向键/Home/End选择、Enter执行、Esc关闭。点击外部、切换条目、滚动页面或改变窗口大小也会关闭菜单。类别选择弹窗中的分类树保持原有选择功能。

## 编辑类别名称和备注

左键选择研究员、路网、场景、案例、算法或批次，在“查看编辑”中修改“类别名称”和“分类备注”，点击“保存修改”。例如将算法名称从 `MIP@MindOPT` 改为 `MIP@MindOPT无平行进路`。

名称最多200个字符，保存时去掉首尾空白，不能为空。同一父类别下的同类型分类不允许重名，不同父类别下可同名。名称与备注一起提交；若发生重名等错误，整个提交不保存，输入内容保留供继续调整。

保存成功后分类树、标题和当前/下级完整路径同步使用新名称。分类ID、层级、基本图所属位置、回溯绑定、run及其时刻表数据均通过原ID保持关联。已保存的运行图和分析数据快照继续保留保存时的内容。此表单用于六级分类，基本图、run和分析子节点仍使用各自的详情界面。

## 求解日志

在 run 的操作栏或右键菜单选择“导入求解日志”，选定文件后点击“保存日志”。日志按 run 保存，可在同一窗口列出并下载原始文件。首次选择文件或取消窗口均不会提交上传。

日志作为原始附件保存，保留原始字节及编码；单个文件须非空且不超过 32 MB。相同 run 下，同名且内容相同的文件复用已有记录；同名但内容不同的日志分别保留。此入口不提取目标函数、gap 等求解指标。

日志随 run 的移动、取消分组保留；删除 run 时一起清理。该功能需要同步并重启后端，启动时自动增加日志存储表；原有时刻表数据不变。

## run下的三类分析子节点

视图、求解日志、延误分析通过统一分析页回看，三小节可独立展开。旧视图使用“查看保存视图”，新分析节点使用“查看保存分析”，日志附件使用“查看求解日志”；左键直接打开，右键只打开菜单。run操作行增加“延误分析”。日志导入后原文件直接出现在run下，保存展示配置可另外命名。详见[run分析指南](run_analysis_guide.md)。
