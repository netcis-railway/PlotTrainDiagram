# 普通 run 导入、查阅与编辑

1. 在分类树选择批次，点击“在当前批次导入run”，或从侧栏进入“run 导入 / 预检”后选择所属批次。
2. 新建时填写名称，编号留空自动分配；覆盖时先选择“覆盖已有run时刻表”，再选择该批次中的目标run，原名称及编号会自动显示。
3. 上传XLSX。表单默认自动识别所有TTT前缀表，也可从下拉菜单指定一个表单。只导入时刻表，文件内其他基础表不导入。一次一个文件；同车跨表区段请先整理，合并功能后续提供。
4. 设置运行基准日及日期解释（默认基准日为2025-04-08，可在下述配置文件修改），点击“run 时刻表预检”。核对有效基本图实际来源、表格、错误/警告和每车实例基准日。有阻断错误时修正Excel/设置后重新预检。
5. 勾选日期、列车实例、适用警告及保存工作状态的确认。覆盖还必须单独确认替换全部时刻表和已保存编辑。
6. 点击确认导入/覆盖，成功后自动回到分类管理并打开该run。名称/编号/批次或基本图、原run内容在预检后发生变化，需要重新预检。

预览表格同时固定左侧“源行”和“NODE_NAME_CHN”列；横向滚动时仍可查看车站及源行号，表头纵向固定，固定列保留原有错误/警告标色和定位信息。

run与基本图共用时刻表编辑界面：顶部筛选按“线路选择、车站选择、列车选择”排列。切换线路全选该线车站，可进一步微调；显示股道/SEQ、三级到发排序、原序恢复、细选列车、首列/前三行锁定、新标签页/Dock、基准日、校验/保存及导出均可用。排序和筛选不修改正式时刻或缩小导出范围。

没有回溯基本图也可接受警告后导入有效TTT，基础资料不足会限制后续绘图/分析；不会从run源文件私自导入基础表或复制基本图。保存run修改不影响基本图。

导出先将当前run时刻表及勾选的基础表更新到受管Excel工作副本，再导出完整副本。默认勾选TTT及当前有效基本图提供的三张基础表；缺少基本图时只更新TTT。run原文件缺少所选基础表时补入；未勾选表单、附加线路数据表、公式及图片等内容保留。勾选表示更新范围，不表示删除未选表单。文件写入/摘要校验失败时保留旧副本，覆盖导入、永久删除和启动恢复会同步清理副本。浏览器另存或替换同名表沿用导出对话框，Firefox使用下载。

最近任务可恢复预检或清理未提交暂存；文件/事务失败保留原run，应用重启会处理上次中断的导入。用户原始Excel不会因导入、覆盖或取消预检被改写。

2026-10-25补充：有效基本图的股道字段允许无正线纯列表，MAIN_TRACK=null不影响run导入或_G校验；正线可兼作到发线，按所选线路/车站合并编号并去重。此前因纯列表被阻断的预检需重新发起，无需补造正线号。

2026-10-25补充已实现：_G为正整数或合法空值，非空时命中实际BaseTT本站任一所属线路的上下行到发线/正线即可，采用OR、不检查编号顺序。列车SEQ可从任意正整数开始，Excel行序不限，但同车须唯一连续；不自动重编号。股道错误独立定位_G，不派生假的SEQ断号。绘图资源仍按所选线路读取。


## 默认运行基准日配置

前端配置文件为 `frontend/import-defaults.json`（相对项目根目录）：

```json
{
  "runDateBase": "2025-04-08"
}
```

`runDateBase` 使用 `YYYY-MM-DD` 格式，作为新打开的 run 时刻表导入表单的默认运行基准日，页面内仍可手动调整。恢复已有预检任务时使用该任务原来保存的日期；不会更改已导入 run 的日期。

修改配置后，开发模式重启前端开发服务并刷新页面；正式部署需要重新构建和发布前端。此配置随前端构建生效，后端无需重启。

## run股道修复

run预检同样阻断缺少_G列，预检结果可直接修复并重新预检。修复资源仅取所属批次当前回溯有效基本图的NODE_INFO，上传文件的基础表不参与。已导入run与基本图使用相同修复窗口，先写入草稿再校验保存。详细规则、占用区间边界与限制见[股道修复指南](track_repair_guide.md)。


## 2026-10-26：SEQ缺列修复与整车平移

普通run与基本图共用缺_SEQ检查及修复。新补SEQ列从1开始，源行跳过但编号连续；已存在的SEQ不自动重编号。与有效基本图的全局SEQ一致性仍复检。run编辑器支持整车到发平移，包含隐藏访问。 详见[SEQ修复](sequence_repair_guide.md)与[整车平移](time_shift_guide.md)。
