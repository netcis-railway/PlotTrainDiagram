# Experiment 固定成员管理

2026-10-29。入口为工作区“Experiment 实验”页签，或项目分类树顶部“新建 Experiment 实验”。

Experiment 使用独立稳定ID，实体存放在研究员、路网、场景、案例、算法或批次中的一个类别下。一类可以存放多个实验。名称去除首尾空白后全局唯一，最多200字符；备注最多20000字符。存放位置只组织实验，不限定成员范围，也不向run提供基本图。

## 树中的实体和引用

实体在存放类别下显示为“实验：名称”，标记“实验实体”，图标为E。每个成员run下同时显示“实验：名称”的虚拟叶节点，标记“实验引用”，图标附箭头。两处点击均打开同一个实验管理页；引用不会复制实验或run，不继续递归展开实验成员。同一run可以参加多个实验。

例如案例下存放“有无平行进路对比”实体；“MIP@MindOPT”和“MIP@MindOPT无平行进路”两个算法下的run各自显示该实验的引用。实验页列出全部成员的完整分类路径、run编号、实际基本图和运行基准日，点击成员名称可返回原run。

修改实验名称会更新全部入口。修改“实体存放类别”并保存可迁移实验实体；成员run归属及基本图不变。分类改名后路径按当前分类信息读取，不以字符串路径充当身份。

## 创建、选择和移除成员

1. 选定实体存放类别，填写名称和备注，点击“创建实验”。也允许先创建空实验。
2. 在“跨类别选择run”中按名称或完整路径搜索并勾选；搜索只改变展示，保留已选项。
3. 可以在“整批加入”勾选一个或多个批次，再点击“加入所选run及批次”。后端在提交时展开这些批次中的当前普通run，并与单选run去重。
4. 当前只有固定成员模式。批次以后新导入的run不会自动加入；再次整批加入可纳入新增run，已经加入的run不重复。
5. 在“当前成员”勾选后点击“移除所选成员”，只删除成员关系和run下的相应虚拟入口，保留run数据与分类归属。

同一个实验成员须解析到同一个实际`base_tt_id`，不能以基本图名称或内容相同替代。成员须有已保存的基准日，且成员和基本图的基准日一致。未分组、无有效图、缺少基准日或基准日不同的run显示原因；不允许加入。一次加入中任一成员无效，整次不写入，不静默忽略错误成员。

实验位置不为成员创建跨旁支/跨研究员基本图绑定。可选列表覆盖所有现存普通run；跨类别选择仍执行上述同基准限制。

## 数据变化、删除和并发

每次列表/详情读取以及加入成员都会重新解析当前基本图和日期。run转移、取消分组、分支新增物理基本图或修改日期后，原成员关系保留；不再满足条件的实验标记“成员不可比较”并列出原因。用户可以移除不兼容成员或修正其归属/日期后刷新。不会自动删除成员或重新选择基准。

删除实验需要在“删除实验”区域显式勾选确认。删除实验实体和全部成员关系，所有run、时刻表、来源文件及run分析节点均保留。

分类递归删除会预览其中的实验实体和受影响成员关系。存在实验实体时阻止删除分类，须先迁移或单独删除实验。用户选择永久删除下属run时，在同一事务清理其成员关系并更新实验修订；选择保留/转移run时保留关系，后续按实时状态显示兼容性。成员关系或相关实验变化会使旧分类删除预览过期。

修改、加入、移除和删除均须提交读到的`revision`；旧修订返回409，保留界面输入以便核对，刷新后重试。写入失败回滚整个事务。数据库启动只兼容创建两个新增表，不迁移旧业务数据、不复制时刻表或文件。

## 当前范围

当前交付包含实验实体、固定成员、导航管理及下述实验分析窗口。自动跟踪、提醒加入、跨run汇总指标和实验分析快照保存属于后续任务；这里的“一致”状态仅说明成员基本图和日期一致。

## 实验数据分析

选择已有实验后，点击“实验数据分析”。按钮先读取当前成员和基准状态；空实验或成员不兼容时不能打开。窗口复用run分析的全宽悬浮窗口，包含可独立展开的“运行图分析（视图）”“求解日志”“延误分析”。按Esc或“返回实验管理”关闭，保留实验管理页的输入。

运行图一次读取所有成员的已保存工作数据，共用实际基本图的线路站轴、车站坐标及股道资源，基本图只叠加一份。绘图列车菜单为基本图及每个成员run各设一列；列标题显示序号、run编号及名称，悬停查看完整分类路径。每列有独立显示开关、“全部/所选车次”、全选/全不选和车次复选列表。选择按run身份区分，同名车次不会互相修改；没有途经所选线路车次的成员仍保留一列。横向空间不足时滚动查看。

成员按run_no升序、同号按稳定内部ID排序。第一个run为红色（#d32f2f），第二个蓝色（#1565c0），第三个深绿色（#006400）；更多成员继续分配颜色。列标题与运行线对应，颜色不按上下行改变，也不被全局样式刷新替换。基本图继续使用原基本图样式；异常段/未判定股道仍沿用原提示样式。各来源“全部”只控制显示，保留勾选名单；“只显示高亮列车”仍为一次性选择操作。

求解日志和延误分析各自在展开后顶部显示独立的run选择栏，列出本实验全部成员的run编号、名称和分类路径；下方明确显示“当前显示”或“当前分析”的run及完整路径。同名run通过完整路径区分，两处选择互不影响。切换后立即显示对应run的日志文件列表或重新计算该run的延误，复用现有文本日志、编码/搜索及单run延误表和曲线。切换时重新挂载对应run的小节，避免上一个run的日志或延误结果残留。日志仍存放在实际run下。

绘图上下文修订包含实验身份/修订及全部成员时刻表和基本图修订。成员、数据或基准变化后，旧请求返回409；点击“刷新图形数据和样式”重新读取。无效成员不静默跳过。实验窗口当前不保存分析节点到任一成员run，不改变时刻表、分类归属或源文件。
