## 四、调度效果评价

### 4.1 延误恢复能力汇总

| 恢复状态 | 列车 | 恢复站点数 | 说明 |
|:---------|:-----|:---------:|:-----|

| ✓ **完全恢复** | G121 | 2 | 天津南→德州东区间内完全吸收240秒延误 |
| ✓ **完全恢复** | G129 | 2 | 滕州东→徐州东区间内完全吸收240秒延误 |
| ✓ **完全恢复** | G135 | 4 | 济南西→枣庄区间内完全吸收420秒延误 |
| ✓ **完全恢复** | G1067 | 1 | 德州东→济南西区间内完全吸收180秒延误（终到站恢复） |
| △ **部分恢复** | G117 | 5（未完全） | 延误从540秒减至83秒，恢复457秒（84.6%），终点站仍余83秒 |
| — **无法恢复** | G323 | 0 | 扰动发生在终点站蚌埠南，无后续运行区间 |

### 4.2 关键结论

1. **延误传播控制良好**：7个扰动事件仅影响对应的7列列车，未传播至其他53列列车。说明京沪高铁运行图的冗余设计有效，列车间具有足够的缓冲时间间隔（到到间隔≥240秒，发发间隔≥180秒，到发间隔≥120秒）。

2. **延误吸收能力显著**：5列中途受扰列车在1-4个站区间内（约50-200公里）完全恢复正点运行，平均每个站间恢复100-150秒延误。这得益于运行图中预留的运行缓冲时间（最小运行时间 vs 计划运行时间之间的差值）。

3. **G117恢复最慢的原因分析**：受扰位置为第18站丹阳北（距北京南约1000公里），距终点上海虹桥仅余5站，可恢复区间有限。540秒初始延误在5个区间内恢复了457秒（84.6%），终点仍余83秒。

4. **G323终端延误**：由于扰动发生在终点站蚌埠南，模型在扰动480秒基础上额外增加了53秒缓冲至533秒，这可能是为了满足与其他列车在蚌埠南的接续约束。

5. **算法高效**：GUROBI 12.0.1在10.96秒内对857,640个约束、83,341个变量的MIP模型求得全局最优解（gap=0.0000%），充分验证了模型的求解效率。
